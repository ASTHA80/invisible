#Invisble 

Every day, we wade through small, quiet frustrations—the extra click, the workaround we’ve memorized by muscle memory, or the dashboard layout that makes no sense. Over time, these jagged edges stop looking like problems. They just look like "the way things are."
​Invisible is a hackathon project built to break that cycle. It is a frontend concept designed to capture the friction you've stopped noticing, trace those isolated moments back to their root causes, deploy thoughtful interventions, and actually measure whether things got better.
